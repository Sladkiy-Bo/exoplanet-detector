# Проект по обнаружению экзопланет

Детекция транзитов экзопланет по кривым блеска звёзд с использованием классических ML-моделей и (в перспективе) глубокого обучения.

## Задача

По временному ряду яркости звезды (light curve) определить, есть ли в системе транзитирующая экзопланета. 
Задача осложнена сильным дисбалансом классов: подтверждённых планет всегда на порядки меньше, чем «обычных» звёзд.

## Данные

**Этап 1 (текущий): Kaggle — "Kepler Labelled Time Series Data"**
- 5087 звёзд в трейне (37 с подтверждённой планетой), 570 в тесте (5 с планетой)
- Каждая звезда — 3197 последовательных измерений потока яркости (flux)

**Этап 2 (в процессе): NASA Exoplanet Archive — таблица Kepler Objects of Interest**
— подробности появятся по мере работы

## Подход

1. Baseline на сырых точках — не сработал: модели не видят сигнал из-за несовпадения фазы транзита между разными звёздами (подробности в notebooks/01_kaggle_baseline.ipynb)
2. Построчная нормализация (медиана/MAD) + инженерные статистические и спектральные признаки (skew, kurtosis, FFT) вместо сырых точек
3. Сравнение моделей с учётом дисбаланса классов (class_weight, scale_pos_weight, BalancedRandomForest)

## Результаты (Kaggle baseline)

| Модель | Recall (CV, класс "планета") |
|---|---|
| Logistic Regression | **0.70** |
| Balanced Random Forest | 0.49 |
| Random Forest | 0.00 |
| XGBoost | 0.00 |

Accuracy как метрика не используется — при таком дисбалансе она вводит в заблуждение
